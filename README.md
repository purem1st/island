# Island

Своя «Dynamic Island» для Windows 10/11 на Tauri 2: пилюля вверху экрана, которая раскрывается при наведении.

## Что умеет первая версия
- Пилюля с часами, раскрывается по наведению (или `Ctrl+Alt+I`)
- История буфера: поиск, закрепление, клик копирует запись
- Полка: перетащи файлы на остров, клик покажет файл в проводнике
- Заметка с автосохранением и напоминания (карточка и звук)
- Командная строка (`Alt+Space`): калькулятор и поиск в интернете

## Что нужно поставить один раз
1. [Node.js](https://nodejs.org) LTS
2. [Rust](https://rustup.rs) и Visual Studio Build Tools (набор «Разработка классических приложений на C++»)
3. WebView2 (на Windows 10/11 уже есть)

## Запуск
```
npm install
npx tauri icon app-icon.svg     # один раз: создаёт иконки в src-tauri/icons
npm run tauri dev               # запуск для разработки
npm run tauri build             # установщик: src-tauri/target/release/bundle/nsis/
```

## Структура
- `src/` интерфейс (HTML, CSS, JS без сборщика)
- `src-tauri/src/main.rs` окно, изменение размера, горячие клавиши
- `src-tauri/tauri.conf.json` и `capabilities/` настройки окна и разрешения

## Известные ограничения первой версии
- Клик по записи буфера копирует её, вставлять нужно самому (`Ctrl+V`). Вставка «в то окно, где печатал» потребует отдельной доработки.
- В буфере только текст (картинки пока нет).
- Окна от администратора и полноэкранные игры могут перекрывать остров.
